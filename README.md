A browser-based chess game designed to provide an interactive and engaging gameplay experience with a clean and responsive interface.

## ✨ Features

* Interactive chess board
* Two-player gameplay
* Responsive user interface
* Basic chess movement and game logic
* Simple and user-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
